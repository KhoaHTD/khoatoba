# Khoatoba

Khoatoba is a lightweight Japanese learning web app focused on interactive exercises.
It features a paper/Washi UI design, a variety of exercise types, and pronunciation via the Web Speech API.

## Setup Instructions

Since this project was initialized manually, please follow these steps to install dependencies and run the app.

1. Ensure you have Node.js installed.
2. Open your terminal in this directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack
- Next.js 14
- TypeScript
- React 18
- Tailwind CSS
- Framer Motion

## Features
- Multiple choice
- Sentence ordering
- Translation
- Fill in the blank
- Matching
- Grammar choice
- Mixed practice
- Pronunciation via Web Speech API
